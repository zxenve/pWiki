# 🥔 Potato Pirate Wiki

An unofficial fan-made wiki for **Potato Pirate**, a card game that teaches programming concepts in a fun and engaging way.

> This is an interactive reference guide showcasing all the cards from Potato Pirate and their programming equivalents across multiple languages.

---

## 🎮 About Potato Pirate

**Potato Pirate** is an innovative card game that makes learning programming concepts fun and interactive. Players collect cards representing programming fundamentals and use them strategically to win. 

👉 **Buy the real game:** [Potato Pirate](https://potatopirates.game/)

---

## 📚 What's Included

This wiki features an interactive card catalog with:

### Card Categories
- **Action Cards** - `Roast`, `Mash`, `Fry` (variable assignment)
- **Control Cards** - Loops (`For x times`, `While > 4`) and conditionals (`If <= 3 Else`)
- **Surprise Cards** - Strategic plays (`Deny`, `Loot`, `Hack`, `Hijack`)
- **Potato King Cards** - 7 collectible cards to win the game
- **Ship Cards** - `The Frying Dutchpan`, `The S.S Megachip`

### Multi-Language Support
View code examples for each card in:
- **JavaScript** 
- **Python**
- **C#**

## ✨ Features

- 🌊 **Animated Ocean Theme** - Beautiful wave and ship animations set a pirate atmosphere
- 🎨 **Interactive Card Gallery** - Click any card to see details and code examples
- 📱 **Responsive Design** - Works on desktop and mobile devices
- 🚀 **Fast & Lightweight** - Pure vanilla JavaScript, no frameworks
- 🎯 **Easy Navigation** - Smooth scrolling with scroll-to-top button

## 💡 How It Works

1. **Wave & Ship Animations** - Continuous background animations create an ocean atmosphere
2. **Card Loading** - Cards are dynamically loaded from `cards.json`
3. **Interactive Overlays** - Click a card to see its description and code examples
4. **Language Tabs** - Switch between JavaScript, Python, and C# implementations
